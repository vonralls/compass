# Compass

A minimalist personal publishing theme for vonralls.com.

## Philosophy

Build. Learn. Share. Repeat.

Compass is a personal digital home for writing about:

- Marketing Technology
- Software & Coding
- AI
- Personal Projects
- Fitness
- Ideas worth exploring

## Design Principles

- Writing comes first
- Simple over complex
- Fast over flashy
- Own the platform
- Build things that last

## Technology

Built with:

- WordPress Block Themes
- PHP
- theme.json
- CSS
- Gutenberg Blocks
